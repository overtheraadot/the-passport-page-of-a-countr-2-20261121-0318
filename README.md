An uncaptioned open passport spread for a country that does not exist: the alpine Republic of Tarnovia (capital Velgrad). Pure-Python PIL drawing — no network, no external images or fonts. The data page carries a drawn portrait of holder Elena Maria Kovac, bilingual field labels, and a valid ICAO machine-readable zone; the facing page carries entry/exit stamps from neighbouring Alpenmark and Dravska (all dated after the 12 MAR 2024 issue date), a Velgrad departure stamp, a 40 TVD fee stamp, and the telling paperwork detail: a visa condition barring the holder from crossing the Velgrad Pass Nov–Mar without a chain permit.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, deterministic — identical bytes on every run).
